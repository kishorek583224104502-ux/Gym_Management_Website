# IronPulse – Gym Management Website

A responsive 5-section website (Home, Services, Dashboard, About, Contact) built with plain HTML, CSS and JavaScript. No build step needed.

## Files
- `index.html` – page structure and content
- `style.css` – styling (responsive, light/dark)
- `script.js` – navigation, calendar and form check

## Deploy on GitHub Pages
1. Create a new repository on GitHub (for example `gym-website`).
2. Upload all files from this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select branch `main` and folder `/ (root)`, then click **Save**.
5. After a minute your site will be live at `https://<your-username>.github.io/gym-website/`.

## Using Git from the terminal
```bash
git init
git add .
git commit -m "Add gym website"
git branch -M main
git remote add origin https://github.com/<your-username>/gym-website.git
git push -u origin main
```
